# Morrow releases

Signed downloads for the Morrow private paid beta.

Download and account setup: https://morrow.aestrum.in/download

Morrow requires macOS 13 or later on an Apple Silicon Mac. An invitation and an active Morrow subscription are required for app access. Connect your own supported ChatGPT account during setup.

This repository contains release artifacts, not application source or customer data. Report beta problems through Morrow or support@aestrum.in.
